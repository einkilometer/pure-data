# Pure Data

The README is targetting pure-data/pure-data/blob/master/doc folder
of the Pure Data documentation of the free real-time computer music system Pd.
The doc-folder contains the patch "paste the subpatch to print as ps.pd"
the doc-subfolders contain postscript representations of the Help-Patches from
pd-0.57-0. The ""paste the subpatch to print as ps.pd"-patch is tested on pd-0.56.2.

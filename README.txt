# Pure Data

The README shows the path to the doc folder of the Pure Data documentation.
Pd the free real-time computer music system.

This root folder contains the patch with tht name "paste the subpatch to print as ps.pd".

The patch is tested on pd-0.56.2 and the support of the canvas.top from the ceammc library,
that you can install with "Find Externals online" from pd deken database.

In the pure-data/blob/master/doc folder are postscript and pdf representations of pd help patches.
